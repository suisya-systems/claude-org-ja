- **全ペインを同一タブ scope に配置する**: broker surface には `new_tab` / `focus_pane` が無く（意図的除外）、pane-addressed 操作（`mcp__org-broker__list_panes` / `send_message` / `inspect_pane` 等）は契約 Surface 4.2 の **SINGLE-TAB MUST**（cross-tab addressing は `pane_not_found` を返す論理 addressing scope）に従う。したがってディスパッチャー・キュレーター・全ワーカーは同一タブ scope に配置する（broker では各ペインが detached 独立セッション / 別 GUI ウィンドウで起動し視覚的に積み重なる訳ではないが、addressing が同一タブ scope に解決される点は契約上同一）。`org-broker` は capability を一切広告せず、`close_pane` / `set_pane_identity` も自身の単一タブモデル内で解決するため、ratified §4.2 の文面が **verbatim** で有効（契約 T-§4.2「Non-advertising backends」: [`docs/contracts/backend-interface-contract.md`]({{ROOT}}docs/contracts/backend-interface-contract.md)）
  - **`ORG_TRANSPORT=renga`（opt-in）面でも結論は同じだが、根拠は capability 条件で読む**（renga の版数条件ではない。各トークンは独立判定 = 契約 T-§cap の independence rule）: `caller_scope`（Group A: `list_panes` / `focus_pane` / `inspect_pane` / `send_keys` / 各 `spawn_*` の `target`）と `caller_scope_close_identity`（Group B: `close_pane` / `set_pane_identity`）は**個別に判定し一方から他方を導出しない**トークンで、確立できた側だけ解決タブが **caller のタブ**（フォーカス非依存）になる（その側ではタブを切り替えても `pane_not_found` は解消しない）。**確立できていない側は client 世代で割れる**: capability ゲートを実装した client は `server_too_old` で **fail closed**（非 transient — リトライもタブ切替もせず upgrade / escalate。契約 T-§6 clause (b)）、gate 以前の client だけが legacy 解決（**ユーザーが見ているタブ**基準）に落ちる。**Group B の legacy 解決は one tab wide ですらなく**、裸の name が active タブ → 他タブ index 順で**先勝ち**フォールスルーするため別組織の同名ペインを rename / close しうる（`close_pane` は不可逆）。緩和策は契約 T-§4.2「Fail-safe consequence for Group B」どおり Group B を**自タブと確認済みの列挙から採った数値 pane id** で当てること。`cross_tab_peers` を確立した経路では messaging だけがタブ横断（`list_peers` 全タブ列挙・数値 id 宛送信。stable name は送信側タブ内）になるが、契約 T-§4.2 が「messaging 到達性から pane 制御到達性を推論するな」を **MUST** で禁じているので配置要件は変わらない。いずれの capability も確立できない経路（renga 1.x を含む pre-capability backend）では pane 制御が**フォーカス中**のタブに向くため別タブの子が addressable でなくなる（2026-04-20 判明の 1.x 系の歴史的根拠。renga 本体側の対応は suisya-systems/renga#71）— どの経路でも **Group A の pane 制御は one tab wide** で、同じ同一タブ要件に帰着する。文面の SoT と分岐手順は [`.claude/skills/org-delegate/references/renga-error-codes.md`](renga-error-codes.md) の `pane_not_found` / `split_refused` 行
