- **全ペインを同一タブ内に配置する**: ディスパッチャー・キュレーター・全ワーカーを同一タブ内に split で積む。結論は契約 T-§4.2 の「Retained from ratified §4.2」で retained（[`docs/contracts/backend-interface-contract.md`]({{ROOT}}docs/contracts/backend-interface-contract.md)）。根拠は renga の版数ではなく **capability を確立できたか**で読む（各トークンは独立判定 = 契約 T-§cap の independence rule。org は `server_info` の `effective_capabilities` で確立する）:
  - **`caller_scope` / `caller_scope_close_identity` を確立した経路** — pane 制御の解決タブが **caller のタブ**（フォーカス非依存）になり、scope は one tab wide のまま。**2 つのトークンは個別に判定し、一方から他方を導出しない**: `caller_scope` は Group A（`list_panes` / `focus_pane` / `inspect_pane` / `send_keys` / 各 `spawn_*` の `target`）だけを、`caller_scope_close_identity` は Group B（`close_pane` / `set_pane_identity`）だけをゲートする。確立できた側では**タブを切り替えても `pane_not_found` は解消しない**（タブ切替を復旧手順にしない）
  - **確立できていない側は client 世代で挙動が割れる**（「未確立 = 従来どおりフォーカス依存」ではない） — capability ゲートを実装した client は要求を送る前に `server_too_old` で **fail closed** にする（**非 transient**。リトライもタブ切替もせず upgrade / re-probe / escalate。契約 T-§6 clause (b)）。gate 以前の client だけが legacy 解決に落ち、そこでは**ユーザーが見ているタブ**基準になる。**Group B の legacy 解決は one tab wide ですらない**: 裸の name は active タブ → 他タブを index 順に探して**先勝ち**でフォールスルーするため、別組織の同名ペイン（`worker-*` は構造的に衝突する）を rename / close しうる（`close_pane` は不可逆）。契約 T-§4.2「Fail-safe consequence for Group B」の緩和策どおり、Group B は**自タブと確認済みの列挙から採った数値 pane id** で当てる
  - **`cross_tab_peers` を確立した経路** — messaging だけが例外（`list_peers` は全タブ列挙、数値 id 宛 `send_message` はタブ横断、stable name は送信側タブ内でのみ解決）。それでも配置要件は変わらない: 契約 T-§4.2 は「messaging 到達性から pane 制御到達性を推論するな」を **MUST** で禁じている
  - **いずれの capability も確立できない経路**（renga 1.x を含む pre-capability backend） — pane 制御は**フォーカス中**のタブに向くため、フォーカスが別タブにある間は同タブの生存ペインすら addressable でなくなる。これが 2026-04-20 判明の 1.x 系の歴史的根拠（renga 本体側の対応は suisya-systems/renga#71）で、同じ同一タブ要件に帰着する
  - どの経路でも **Group A の pane 制御は one tab wide** なので、`new_tab` で子を別タブに置くと `list_panes` / `inspect_pane` / `send_keys` から観測・操作できなくなる（同一タブ要件の現行根拠）。**`close_pane` は Group B なので「届かなくなる」では済まない**: 上記 legacy 解決の経路では裸の name が別タブの同名ペインに当たりうるため、退役操作が**別タブを撃つ**側に倒れる。文面の SoT と誤読時の分岐手順は [`.claude/skills/org-delegate/references/renga-error-codes.md`](renga-error-codes.md) の `pane_not_found` / `split_refused` 行
