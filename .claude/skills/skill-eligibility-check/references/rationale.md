# skill-eligibility-check — 規律の由来

[`.claude/skills/skill-eligibility-check/SKILL.md`](../SKILL.md) 本文から移した「なぜこの規律があるか」の記録。規律そのものは本文に残してあり、ここにあるのは由来だけ。手順を実行するために読む必要はない。

## 1. 判定を 1 つのスキルに集める理由

skill 化の判定基準が org-retro と org-curate の 2 箇所に分散すると必ず乖離するため、このスキルを判定の正本として双方から呼ぶ。知見の統合基準（[`.claude/skills/org-curate/references/knowledge-standards.md`](../../org-curate/references/knowledge-standards.md)）には skill 化判定を重複定義しない。

## 2. 推奨の閾値を 3 点に置いた理由（Step 2）

org-retro の旧版にあった「2 つ以上で推奨」よりやや保守的にし、候補止まり（2 点）の層を明示的に作ることで、skill 検索面のノイズを予防する。
