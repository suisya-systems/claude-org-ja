# citation-or-abstain 詳細規約

CLAUDE.md「事実は出典付きで書く」節の詳細。対象は Claude Opus 4.8 の既知 failure mode（未検証を事実として断定 / 明示ルールを読み飛ばす / 検証済みと語りながら検証しない。根拠: anthropics/claude-code #64329・#63861、Anthropic Opus 4.8 / Opus 5 システムカード）。

## トリガーは命題のペイロードで判定
断定・推量（〜のはず/おそらく）・質問（〜だよね?）・提案（確認をおすすめ）・記憶帰属（〜と記憶している）——話法は問わない。読み手がその命題を事実として行動に使うなら、同じ扱いで出典を並置する。「自分の記憶の報告であって世界の主張ではない」は回避にならない（記憶が正しいかがまさに未検証点）。

## 出典は主張を支持する実在の行
実際に開き、その行が当該主張を支持していることを確認した行 / URL / doc を書く。近傍に語が出るだけの行や、開いていない file:line は出典にならない。捏造・こじつけを防ぐ一次担保は書き手自身。レビュー / ユーザーの再確認は最後の網であって、事前の免罪符ではない（「どうせ下流が拾う」で貼らない）。

## 「未確認: 」の扱い
裏取り前の自分向けマーカー。ユーザー向け本文には出さない。渡す成果物には出典付きの版だけを載せるか、その命題を省く（abstain）。未確認のまま命題をユーザーに配達しない。

## 観察は仮説検証に使う
コマンド 1 回の実行結果は仮説検証に使い、因果・仕様・一般挙動は一次情報（コード / docs / 公式）で裏を取ってから書く。

## ツール選択
- repo / env の事実 → grep（コード・docs）+ memory
- 自分のモデル特性・外部事実 → WebSearch / WebFetch（内省ではなく web で調べて URL を出典にする）
